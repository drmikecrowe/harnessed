# hindsight

Vectorize Hindsight — AlloyDB-backed memory and recall (`retain` / `recall` / `reflect`).

Wired as an **HTTP MCP server**: hatago proxies a *host-running* Hindsight server by URL, so the
server's lifecycle is yours, not harnessed's. The bearer token and bank ID in `recipe.yaml` are
placeholders you must replace.

Upstream is a hosted product rather than a public repo: <https://hindsight.vectorize.io>
