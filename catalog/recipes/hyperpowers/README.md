# hyperpowers

A markdown-first dev-workflow skill suite — brainstorming, planning, TDD, execution, review, and
verification — with task tracking kept in repo-local docs.

Ships as skills, commands, and agents installed by the recipe's `install.sh` — in the container
image and on a `--host` launch alike. No MCP server.

Upstream: <https://github.com/withzombies/hyperpowers>
