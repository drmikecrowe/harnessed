# mattpocock-skills

Matt Pocock's "Skills for Real Engineers": small, composable skills for grilling a plan, turning it into a spec and tickets, TDD, code review, domain modelling, and handoff.

Ships 27 skills from the `engineering` and `productivity` categories, the same set as the upstream Claude Code plugin. No MCP server.

Run `/setup-matt-pocock-skills` once per repo before the tracker-aware skills (`/triage`, `/to-tickets`).

Upstream: <https://github.com/mattpocock/skills> (MIT)
