155:- **A version change makes the profile stale.** The build stamp includes the harnessed version. When the harnessed that launches the agent differs from the one that built the profile, for example a release install and a source checkout, the profile counts as stale. 104:## Atlas
106:Atlas has no settings screen for custom agents. Add the entry to its installed-agents file by hand:
108:1. Quit Atlas. It rewrites the file on every agent install and uninstall, so an edit made while it runs can be lost.
109:2. Edit `~/.local/share/dev.atlas.ide/external-agents/installed.json`. A development build of Atlas uses `~/.local/share/dev.atlas.ide.dev/external-agents/installed.json` instead. Create the file if it does not exist.
122:3. Keep the JSON valid. Atlas treats a malformed file as empty. `jq . installed.json` is a quick check.
123:4. Start Atlas and pick the agent.
125:Atlas writes the agent's stderr into its own log as `agent stderr:` lines.
